## 阶段二：功能优化（测试通过后）

### 优先级排序

**高优先级（体验核心）**
- [ ] 提交图性能优化：虚拟滚动（1000+提交不卡顿）
- [ ] DiffView 性能：大文件Diff懒加载
- [ ] 暗色主题配色精调：对标 Fork 配色一致性
- [ ] 确认对话框统一：原生 confirm() → 自定义弹窗组件
- [ ] 操作反馈优化：所有 git 操作 loading → 成功/失败 toast

**中优先级（效率提升）**
- [ ] 最近打开仓库记忆：启动时恢复上次仓库
- [ ] 文件树排序：按名称/修改时间/状态排序
- [ ] 提交搜索增强：支持正则/作者/日期范围
- [ ] DiffView 并排/统一视图切换
- [ ] 键盘导航：提交图 j/k 上下选择，Enter 查看详情
- [ ] 拖拽文件 Stage/Unstage（从文件列表拖到暂存区）

**低优先级（锦上添花）**
- [ ] 提交图缩放：鼠标滚轮缩放提交图
- [ ] 自定义快捷键设置
- [ ] Git Flow 工作流支持
- [ ] 提交签名验证状态显示
- [ ] Worktree 管理

## 阶段三：UI/UX 优化设计

### 视觉优化

| 项目 | 当前状态 | 目标状态 |
|------|---------|---------|
| 暗色主题配色 | CSS变量已定义，但色值未精调 | 对标Fork/GitKraken的灰阶层次 |
| 提交图分支线 | Bezier曲线已实现 | 增加发光效果/阴影，增强空间感 |
| 图标系统 | 部分用emoji/文字 | 统一SVG图标库 |
| 字体排版 | 系统默认 | 等宽字体（代码区）+ 无衬线（UI） |
| 动画过渡 | 基本无 | 操作反馈微动画（150-200ms） |
| 空状态 | 无处理 | 引导性空状态插画+文案 |

### 交互优化

| 项目 | 优化方向 |
|------|---------|
| 文件列表 | 拖拽排序/批量操作/Shift多选 |
| 提交图 | 双击提交→详情面板、右键上下文增强 |
| DiffView | 行内编辑（Stage部分Hunk） |
| 侧边栏 | 折叠记忆/拖拽排序分组 |
| 命令面板 | 最近命令/模糊匹配增强 |
| 状态栏 | 可点击ahead/behind→Push/Pull |

## 执行节奏建议

1. **本周**：本地跑通 P0 冒烟测试（10项），记录问题
2. **P0通过后**：跑 P1 + P2，边测边修
3. **测试全通过**：开始阶段二高优先级优化
4. **高优完成后**：阶段三 UI/UX 精调
5. **每个阶段结束**：更新版本号，打 tag，发版
