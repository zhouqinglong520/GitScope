# GitGUI 产品需求文档 (PRD)

## 1. 产品定位

**一句话**：面向国内开发者的现代 Git 图形化客户端，原生中文、深度集成国内平台、核心免费。

**目标用户**：
- 核心用户：1-5年经验的国内开发者，日常使用 Git 但不熟悉 CLI
- 扩展用户：团队技术负责人，需要管理多个仓库和 Code Review

**竞品差异化**：
| 维度 | 竞品现状 | 我们 |
|------|----------|------|
| 中文体验 | 机器翻译或无 | 原生中文设计 |
| 国内平台 | 无/弱支持 | Gitee/Coding 深度集成 |
| 性能 | Sourcetree慢、GitKraken吃内存 | 轻量高效 |
| 价格 | GitKraken私有仓库收费、Fork收费 | 核心免费 |
| AI | 仅GitKraken有 | 接入国产模型，中文commit |

## 2. 技术方案

**MVP**：Electron + Node.js + React + TypeScript
- 前端：React + TypeScript
- Git 操作：isomorphic-git（纯 JS）+ git CLI 降级
- 打包：electron-builder
- 后期演进：核心渲染层迁移至 Tauri + Rust

## 3. MVP 功能范围（P0）

### 3.1 仓库管理
- 打开本地仓库
- 克隆远程仓库（HTTPS/SSH）
- 初始化新仓库
- 仓库列表（最近打开、收藏）

### 3.2 提交操作
- 暂存区管理（文件级别 + hunk 级别）
- Commit（支持多行消息）
- Amend 提交
- Undo 上次提交

### 3.3 远程同步
- Push / Pull / Fetch
- HTTPS 和 SSH 双协议
- 远程仓库管理（添加/删除/修改 remote）

### 3.4 分支管理
- 创建/切换/删除分支
- 合并分支
- 分支列表（本地 + 远程）

### 3.5 可视化提交图
- 分支拓扑图（DAG）
- 提交详情面板
- 搜索提交记录
- 按作者/日期/消息筛选

### 3.6 差异查看
- Side-by-side 对比
- Unified 视图
- 文件级别 diff 列表

### 3.7 中文界面
- 完整中文 UI（非翻译，原生设计）
- 中英切换

### 3.8 Gitee 集成
- OAuth2 一键登录
- 一键克隆 Gitee 仓库
- 基础 push/pull

### 3.9 凭证管理
- 安全存储 PAT
- SSH Key 管理
- 系统钥匙串集成

## 4. V1.1 功能（P1）

- 可视化三面板冲突解决器
- 交互式变基（拖拽排序、squash、reword）

## 6. 设计原则

1. **快**：启动 < 3秒，操作响应 < 200ms
2. **简单**：核心操作 2 步内完成，不堆按钮
3. **中文优先**：不是翻译，是原生中文交互设计
4. **渐进式**：新手开箱即用，高手深度可调

## 7. 成功指标（MVP 上线后 3 个月）

- 日活用户 > 1000
- NPS > 40
- 大仓库（1万+文件）操作流畅度评分 > 4/5
- Gitee 绑定用户占比 > 30%
