## Git Flow 颜色

| 分支类型 | 颜色 | 值 |
|---------|------|-----|
| Feature | 蓝色 | `#58a6ff` |
| Release | 橙色 | `#d29922` |
| Hotfix | 危险红 | `#f85149` |

## 圆角

| 元素 | 值 |
|------|-----|
| 卡片 | `12px` |
| 输入框 / 按钮 | `6px` |
| 选项面板 | `8px` |

## 分支颜色映射

CommitGraph 和 Sidebar 共享同一组 `BRANCH_COLORS` 常量，通过分支名哈希映射保证颜色一致性：

```
#58a6ff, #f85149, #3fb950, #d29922, #bc8cff,
#f0883e, #39d353, #ff7b72, #79c0ff, #d2a8ff,
#56d4dd, #e8c547, #db61a2, #7ee787, #ffa657
```
